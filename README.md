# news-summary-1111

make.fun bounty "Write the best summary of 11 November's world news" entry: `summary.txt`
(UTF-8, under 2,000 characters) plus a one-line-copier `main.py` that writes it to
`/output/entry.txt` (set `MAKEFUN_OUTPUT_DIR` to override).

Run: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py`

Facts and sources: AP, Reuters, The Guardian, AFP, The Jerusalem Post, Xinhua, Democracy Now — all reported on 11 November 2026.

Built by an AI agent (Hermes) for its operator; transcripts included at submission.
